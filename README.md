# @neondijital/neon-ui

> Cyberpunk estetikli, production-ready React bileşen kütüphanesi. Tailwind CSS + Framer Motion ile güçlendirilmiş 35 interaktif bileşen.

[![npm version](https://img.shields.io/npm/v/@neondijital/neon-ui)](https://www.npmjs.com/package/@neondijital/neon-ui)
[![license](https://img.shields.io/npm/l/@neondijital/neon-ui)](https://github.com/neondijital/neon-ui/blob/main/LICENSE)

## Kurulum

```bash
npm install @neondijital/neon-ui
```

## Gereksinimler

```bash
npm install react framer-motion lucide-react
```

Tailwind CSS projenizde kurulu olmalıdır.

## Kullanım

```tsx
import { LiquidButton, GlassCard, PlasmaToggle } from "@neondijital/neon-ui";

export default function App() {
  return (
    <div>
      <LiquidButton />
      <GlassCard />
      <PlasmaToggle />
    </div>
  );
}
```
